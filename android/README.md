# SCENE/044 Android release

This is a Bubblewrap Trusted Web Activity for `https://scene044.in/` with package ID `in.scene044.app`. The booking UI remains on the website; this Android project does not duplicate it.

## Build

Use JDK 17, Android SDK Platform 36, and the Gradle wrapper. From this directory, run `bubblewrap build`. The app uses Android Gradle Plugin 8.10.1 because API 36 is not supported by the plugin version generated by Bubblewrap. The minimum Android version is API 24, required by `androidbrowserhelper`.

The upload key is `android.keystore` with alias `scene044`. It is intentionally ignored by Git. Its password is stored on the original Mac in macOS Keychain under service `scene044-play-upload-key-password` and account `scene044-play-upload`. Back up **both the keystore and password** securely before a release; they are needed for future app updates. Never commit the key, password, or signed bundles.

The signed bundle is output as `app-release-bundle.aab`. Increment `appVersionCode` for each upload. Play App Signing will provide the **app-signing** certificate SHA-256; add that certificate (not just the local upload-key certificate) to `https://scene044.in/.well-known/assetlinks.json` before release so the Trusted Web Activity opens without a browser toolbar.

The Play listing can use `https://scene044.in/privacy` for the privacy policy and `https://scene044.in/account/delete` for account-deletion instructions. Store declarations and app access instructions must be reviewed against the live booking, WhatsApp login, payment, and review flows before submission.
